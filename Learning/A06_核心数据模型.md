# A06 - 核心数据模型

## 模块名称

`Agent/src/models/schemas.py` + `Agent/src/agent/state.py`

---

## 概述

本模块定义了婉晴 AI 项目中所有核心数据结构，采用 **Pydantic v2** 进行数据校验：

- `schemas.py`：共享业务模型（感知数据、情感向量、干预决策、记忆模型等）
- `state.py`：`AgentState` —— 贯穿 LangGraph 图的全局状态容器

> **设计原则**：字段设为 `Optional` 并提供默认值，避免节点因字段缺失报错。

## 枚举类型

### EmotionLabel - 情绪标签（10类）

```python
class EmotionLabel(str, Enum):
    ANXIETY = "焦虑"
    DEPRESSION = "沮丧"
    CALM = "平静"
    HAPPY = "开心"
    FATIGUE = "疲惫"
    ANGER = "愤怒"
    FEAR = "恐惧"
    DISGUST = "厌恶"
    SURPRISE = "惊讶"
    NEUTRAL = "中性"
```

> 注意：中文枚举值用于前端展示和 Prompt 推理，与英文 `primary_emotion`（来自 AU 模型）区分。

## 感知数据模型

### HeadPose - 头部姿态

```python
class HeadPose(BaseModel):
    pitch: float  # 俯仰角：负值=低头
    yaw: float    # 偏航角：左右偏转
    roll: float   # 翻滚角
```

### AUIntensities - 面部动作单元强度（0~1）

```python
class AUIntensities(BaseModel):
    AU1: float   # 内眉上扬
    AU2: float   # 外眉上扬
    AU4: float   # 皱眉（焦虑/悲伤）
    AU5: float   # 瞪眼
    AU6: float   # 颧骨上提（微笑）
    AU12: float  # 嘴角上扬（微笑）
    AU15: float  # 嘴角下垂（悲伤）
    AU17: float  # 下颌抬起
    primary_emotion: str   # AU 模型推断的基础情绪（英文）
    confidence: float       # AU 模型置信度
```

> **关键指标**：`AU4 > 0.7` + `AU15 > 0.5` → 沮丧 / 焦虑信号

### AudioFeatures - 音频特征

```python
class AudioFeatures(BaseModel):
    pitch: float       # 基频 F0（Hz）
    loudness: float    # 响度（归一化 0~1）
    mfcc: list[float]  # MFCC 系数
    speaking: bool     # 是否正在说话（VAD）
```

### PerceptionData - 多模态感知快照

```python
class PerceptionData(BaseModel):
    timestamp: int          # Unix 毫秒时间戳
    session_id: str
    head_pose: HeadPose
    blink_rate: float      # 眨眼频率（次/分钟）
    au: AUIntensities
    audio: AudioFeatures
    focus_level: float     # 专注度估计（0~1）
```

## 情感分析模型

### ValenceArousal - PAD 情感空间子集

```python
class ValenceArousal(BaseModel):
    valence: float    # 效价：-1 负面 ~ +1 正面
    arousal: float     # 唤醒度：0 平静 ~ 1 激动
    dominance: float   # 优势度（可选）
```

### QwenAnalysis - Qwen-VL-Max 多模态分析

```python
class QwenAnalysis(BaseModel):
    timestamp: int
    primary_emotion: str           # 主要情绪（中文）
    emotion_intensity: float
    confidence: float
    facial_cues: list[str]         # 面部线索描述
    cognitive_distortions: list[str]
    scene_description: str         # 场景自然语言描述
    valence_arousal: ValenceArousal
    raw_response: str              # 模型原始输出（调试用）
```

### EmotionVector - 融合后的情感向量

```python
class EmotionVector(BaseModel):
    timestamp: int
    session_id: str

    # 核心情绪
    primary_emotion: EmotionLabel
    secondary_emotion: EmotionLabel | None
    intensity: float               # 情绪强度（0~1）

    # PAD 情感空间
    valence: float                 # 效价
    arousal: float                 # 唤醒度
    dominance: float

    # 认知分析（CBT）
    cognitive_distortions: list[CognitiveDistortion]

    # 可信度
    confidence: float              # 综合置信度
    reasoning: str                 # LLM 推理过程

    # 证据与上下文
    evidence: dict[str, Any]       # 支持判断的证据
    history_context: dict[str, Any] # 历史情感上下文
```

## AgentState - LangGraph 全局状态容器

```python
class AgentState(MessagesState):
    # ===== 会话标识 =====
    session_id: str
    user_id: str

    # ===== 对话历史 =====
    conversation_history: list[dict]  # 由 Java 传入或从 Redis 读取

    # ===== 感知数据 =====
    latest_perception: PerceptionData | None
    qwen_analysis: QwenAnalysis | None
    is_focused_mode: bool  # True=专注模式，False=走神模式

    # ===== 情感识别 =====
    current_emotion: EmotionVector | None
    emotion_history: list[dict]  # 最近 30 分钟情感记录

    # ===== 干预决策 =====
    intervention_decision: InterventionDecision | None
    last_intervention_time: int  # 上次干预时间戳（毫秒）
    user_rejection_penalty: float # 用户拒绝惩罚系数 [0.5, 1.5]

    # ===== 记忆上下文 =====
    user_profile: dict[str, Any]
    retrieved_long_term_memories: list[str]

    # ===== RAG 知识库 =====
    retrieved_knowledge_cards: list[str]
    retrieved_knowledge_cards_with_meta: list[dict]  # 含 metadata

    # ===== 任务上下文 =====
    task_phase: str   # experiment_task / idle / post_task
    user_input: str   # 本轮用户输入（可为空）

    # ===== 系统状态 =====
    system_health: dict[str, Any]  # java_backend_online, redis_connected 等

    # ===== 路由控制 =====
    next_node: str

    # ===== 最终响应 =====
    final_response: dict[str, Any]
```

### 字段来源速查

| 字段 | 来源 |
|------|------|
| `session_id` / `user_id` | Java 请求体传入 |
| `latest_perception` | 感知微服务写入 Redis，主流程读取 |
| `conversation_history` | Java 请求体传入，或从 Redis 读取 |
| `is_focused_mode` | `fuse_emotion` 节点判断后写入 |
| `current_emotion` | `fuse_emotion` 节点输出 |
| `intervention_decision` | `decide_intervention` 节点输出 |
| `user_rejection_penalty` | Java 统计历史反馈后传入 |
| `user_profile` | 会话启动时从 MySQL 加载 |
| `retrieved_long_term_memories` | `retrieve_knowledge` 节点从 ChromaDB 检索 |
| `retrieved_knowledge_cards` | `retrieve_knowledge` 节点从 Markdown 文件检索 |
| `final_response` | `return_result_node` 写入 |
