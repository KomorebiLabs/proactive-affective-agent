## 四、项目架构一句话

如果只能记住一件事，请记住：

> **婉晴AI是一个"感知→情感融合→干预决策→关怀回复"的循环AI系统，前端展示情感可视化，Java作为HTTP网关，Python感知服务和Python Agent分别负责数据采集和智能决策。**

详细解释见 `A07_Agent整体运转逻辑.md`。

## 五、快速问答

| 问题 | 答案 |
|------|------|
| 婉晴的"大脑"在哪？ | `Agent/src/agent/graph.py` —— LangGraph状态机 |
| 感知数据存在哪？ | Redis，key = `emotion:realtime:{session_id}` |
| 对话历史存在哪？ | Redis（短期）+ ChromaDB（长期） |
| 前端和后端怎么通信？ | SSE流式推送（Java → 前端） |
| Agent和Java怎么通信？ | HTTP POST + SSE流式返回（Java → Agent） |
| TTS语音从哪来？ | Edge TTS或火山引擎，通过WebSocket推向前端 |
| Notion日记怎么写？ | Python Agent调用Notion API，通过LangChain Function Calling |
| 心理学知识从哪来？ | ChromaDB RAG检索，知识卡片在 `Agent/knowledge_cards/` |

## 六、源码文件速查

### Python Agent（端口8001）

| 文件 | 职责 |
|------|------|
| `src/agent/graph.py` | LangGraph图定义：节点注册 + 边连接 + 条件路由 |
| `src/agent/state.py` | AgentState状态定义：贯穿整个图的共享数据 |
| `src/agent/nodes/collect_perception.py` | 从Redis读取最新感知数据 |
| `src/agent/nodes/fuse_emotion.py` | 调用DeepSeek做OCC八维情感融合 |
| `src/agent/nodes/decide_intervention.py` | 五因子评分，决定SILENT/SUBTLE/INTERVENE |
| `src/agent/nodes/generate_reply.py` | 组装Prompt，调用DeepSeek生成关怀回复 |
| `src/models/schemas.py` | 所有Pydantic数据模型：EmotionVector、InterventionDecision等 |
| `src/memory/short_term.py` | Redis短期记忆：对话历史存储与摘要压缩 |
| `src/memory/long_term.py` | ChromaDB长期记忆：向量存储与语义检索 |
| `src/rag/retriever.py` | RAG检索：心理学知识卡片检索 |
| `src/utils/tts.py` | TTS语音合成：Edge TTS + 火山引擎 |
| `src/agent/tools/notion_tool.py` | Notion情绪日记Function Calling |

### Python感知服务（端口8000）

| 文件 | 职责 |
|------|------|
| `ai_assistant/core/perception_engine.py` | 感知引擎：摄像头采集 + MediaPipe + openSMILE |
| `ai_assistant/core/audio_feature_extractor.py` | 音频特征提取 |
| `api/websocket.py` | WebSocket路由：广播感知数据给前端 |

### Java后端（端口8080）

| 文件 | 职责 |
|------|------|
| `controller/ChatController.java` | SSE聊天端点：接收前端请求，调用Agent，透传SSE流 |
| `client/AgentClient.java` | Agent通信客户端：WebClient SSE透传 |
| `service/impl/SessionServiceImpl.java` | 会话管理：创建会话、Redis历史写入 |

### 前端（端口5173）

| 文件 | 职责 |
|------|------|
| `src/App.vue` | 主入口：SSE连接 + WebSocket连接 + 光晕动画调度 |
| `src/store/appStore.js` | Pinia状态：OCC向量、聊天历史、连接状态 |
| `src/components/ChatWindow.vue` | 聊天窗口UI |
| `src/components/EmotionRadar.vue` | ECharts雷达图 |
| `src/components/PortraitBox.vue` | 婉晴立绘 |

## 七、项目启动顺序

```
1. 启动Redis（端口6379）
2. 启动MySQL（端口3306，已作系统服务则跳过）
3. 启动Python感知服务（端口8000）：
   cd backend && python main.py
4. 启动Python Agent（端口8001）：
   cd Agent && python main.py
5. 启动Java后端（端口8080）：
   cd backend && ./mvnw.cmd spring-boot:run
6. 启动前端（端口5173）：
   cd frontend && npm run dev
```

访问 `http://localhost:5173` 验证。
