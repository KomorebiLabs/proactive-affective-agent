# ACT当下觉察技术·呼吸锚定法
## 一、适用时机（什么时候用）
当用户意识脱离当下，陷入**对过去的反刍或对未来的灾难化想象**，失去对现实的感知，生活处于「走神内耗」状态，甚至出现解离感时使用。

## 二、核心操作步骤（怎么用）
1. 引导用户找一个舒适的姿势，将注意力拉回**呼吸本身**；
2. 感受气息进出鼻腔的清凉与温热，或胸腔/腹部的起伏；
3. 觉察当下的身体姿态、与外界的接触（如脚踩地面、手触物体）；
4. 留意当下环境的感官细节（所见、所听、所触），不分析、不联想；
5. 当思维再次飘走，无需自责，温和地说「我又飘走了」，将注意力重新拉回呼吸。

## 三、技术目的与价值（为什么用）
以**呼吸为锚点**，快速将意识从过去/未来的思维陷阱拉回当下现实，重建对环境的感知，减少无意义内耗，提升生活的真实感与掌控感。

## 四、标准话术示例
“我们先把注意力放在呼吸上，感受空气进来又出去。如果脑子想到别的事也没关系，发现了就再轻轻拉回来，感受现在就好。”
