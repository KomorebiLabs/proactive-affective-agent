# ACT认知解离·思维列车技术
## 一、适用时机（什么时候用）
当用户陷入**连绵不断的负面思维流**，像被火车拖着走一样无法停下，情绪随想法波动剧烈，无法专注当下时使用。

## 二、核心操作步骤（怎么用）
1. 引导用户想象自己站在火车站台，身体稳稳扎根地面；
2. 将头脑中的每一个想法想象成一列驶过的火车车厢，不跳上火车、不跟随想法走；
3. 允许火车（想法）自由驶来、驶离，不试图拦住、赶走或分析任何一节车厢；
4. 保持站在站台的观察者视角，只是看着想法来来去去；
5. 当发现自己跟随想法走了，温和地说「我又上车了」，再把注意力拉回站台。

## 三、技术目的与价值（为什么用）
通过**具象化隐喻**让用户从「思维参与者」转变为「思维观察者」，切断与想法的认同，避免被思维流裹挟，重建对意识的掌控感。

## 四、标准话术示例
“我们把这些不停冒出来的想法想象成一列火车，你就站在站台上，看着它们一节节开过去，不用上车跟着走，就安静地看着就好。”
