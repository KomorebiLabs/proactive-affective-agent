# ACT认知解离·前缀标记法
## 一、适用时机（什么时候用）
当用户出现**认知融合**，即坚信头脑中的负面想法是客观事实，被想法绑架情绪与行为，无法与思维拉开心理距离，陷入自我否定或灾难化想象时，立即使用。

## 二、核心操作步骤（怎么用）
1. 引导用户觉察当下出现的具体负面想法，不反驳、不压抑、不评判；
2. 在想法前固定加入解离前缀，任选其一：
   - 「我注意到我有一个想法：……」
   - 「我的头脑正在告诉我：……」
   - 「我正在产生一个念头：……」
3. 完整说出带前缀的句子，缓慢重复1-2次；
4. 观察想法只是短暂出现的心理事件，而非自我本身或客观真相；
5. 无需刻意消除想法，仅保持观察者视角即可。

## 三、技术目的与价值（为什么用）
通过**语言标记**快速建立思维与自我的心理距离，破除「想法=事实」的认知融合误区，降低负面思维对情绪和行为的支配力，让用户从「被想法控制」转向「观察想法」，恢复理性觉察。

## 四、标准话术示例
“你现在脑海里的这个念头，只是头脑产生的一个想法，不是事实。我们试着说：‘我注意到，我的头脑在想……’，看看和这个想法拉开一点距离，会不会好一些？”
