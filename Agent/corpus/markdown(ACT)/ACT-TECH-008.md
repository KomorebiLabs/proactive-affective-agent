# ACT自我为背景技术·观察者自我练习
## 一、适用时机（什么时候用）
当用户将**情绪或想法等同于自我身份**，陷入「我就是这样的人」的自我否定，无法区分「我有这个感受」与「我就是这个感受」，自我价值感极低时使用。

## 二、核心操作步骤（怎么用）
1. 引导用户找一个舒适的姿势，闭上眼睛，想象自己是天空；
2. 将头脑中的想法、情绪、感受想象成天空中的云朵、飞鸟、风雨；
3. 觉察天空始终存在，而云朵、风雨只是短暂出现、变化的现象；
4. 对自己说：「我是容纳这些感受的天空，不是飘过的云朵」；
5. 保持观察者视角，意识到自我是稳定的背景，而非流动的情绪/想法。

## 三、技术目的与价值（为什么用）
通过**隐喻**帮助用户建立「观察者自我」，区分「自我本质」与「短暂的心理体验」，避免因负面情绪/想法否定自我，重建稳定的自我认同感。

## 四、标准话术示例
“想象你是一片广阔的天空，那些难过的想法、难受的感受，只是天空中飘过的云朵。云朵会来会走，但天空一直都在，你就是这片天空。”
