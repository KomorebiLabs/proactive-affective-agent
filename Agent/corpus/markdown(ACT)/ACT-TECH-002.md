# ACT认知解离·重复命名法（牛奶牛奶技术）
## 一、适用时机（什么时候用）
当用户被**单一负面想法反复纠缠**，陷入「越想摆脱越强烈」的思维循环，情绪被执念牢牢控制，无法正常思考或行动时使用。

## 二、核心操作步骤（怎么用）
1. 引导用户提炼当前最困扰的核心想法为1-2个简短词语（如「我没用」「会失败」）；
2. 以平稳、单调、缓慢的语速，像念「牛奶、牛奶」一样重复念出这个词语；
3. 持续重复20-30次，过程中不联想内容、不赋予情绪意义；
4. 观察词语逐渐变得陌生、空洞，失去原本的情绪冲击力；
5. 停止重复后，将注意力拉回当下的呼吸或环境感官。

## 三、技术目的与价值（为什么用）
通过**机械重复**消解想法的情绪意义与重要性，让用户意识到想法只是语言符号，而非需要严肃对待的真相，从而打破思维固着，减少执念对情绪的控制。

## 四、标准话术示例
“我们把这个让你难受的想法提炼成一个词，然后慢慢、平淡地重复念它，就像念‘牛奶、牛奶’一样，看看它会不会变得没那么有力量？”
