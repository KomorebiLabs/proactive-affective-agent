# 愤怒情绪暂停技术
## 一、适用时机（什么时候用）
用户**愤怒情绪爆发、火气上头、想吵架、想摔东西、即将做出冲动行为**时，紧急使用。
## 二、核心操作步骤（怎么用）
1. 愤怒升起瞬间，**立刻默念“暂停”**，强制终止当下反应；
2. 马上离开触发场景，到安静、空旷的环境停留10分钟；
3. 做3轮深呼吸，平复心跳与躯体愤怒反应；
4. 情绪冷静后，再理性分析事件与想法。
## 三、技术目的与价值（为什么用）
愤怒是**高唤醒情绪**，暂停技术能避免冲动伤人伤己，给情绪降温，实现理性控制。
## 四、标准话术示例
“我现在情绪很激动，需要先冷静十分钟，等我们都平静了，再好好沟通这件事。”
