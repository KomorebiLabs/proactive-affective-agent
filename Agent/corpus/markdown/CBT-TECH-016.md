# 应对卡片制作使用技术
## 一、适用时机（什么时候用）
用户**情绪失控、思维混乱、需要快速自我安抚**时使用。
## 二、核心操作步骤（怎么用）
1. 卡片正面：写高频负面想法；
2. 背面：写理性替代想法+放松话术；
3. 随身携带，发作时快速阅读。
## 三、技术目的与价值（为什么用）
提供**即时心理支持**，快速纠正负面思维，实现自我救助。
## 四、标准话术示例
“现在看看手里的卡片，读一读上面的话，你会慢慢平静下来。”
