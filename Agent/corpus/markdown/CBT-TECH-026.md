# CBT五步问题解决技术
## 一、适用时机（什么时候用）
用户**遇到现实问题、不知所措、焦虑无助**时使用。
## 二、核心操作步骤（怎么用）
1. 定义清楚问题；
2. 设定可行目标；
3. 想所有解决方案；
4. 选最优方案；
5. 执行+复盘。
## 三、技术目的与价值（为什么用）
把**混乱问题结构化**，提升解决能力，降低无助感。
## 四、标准话术示例
“我们一步一步来，先把问题说清楚，再想办法，一定能解决。”
