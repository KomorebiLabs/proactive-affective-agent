# 腹式呼吸放松法
## 一、适用时机（什么时候用）
用户出现**躯体紧张、心跳加快、胸闷、呼吸急促、烦躁不安、轻度焦虑上升**，任何时间、任何场景均可随时使用，无场地限制。
## 二、核心操作步骤（怎么用）
1. 引导用户采取舒适姿势（坐/站/躺均可），一只手放在胸口，一只手放在腹部；
2. 用鼻子**缓慢吸气4秒**，感受腹部像气球一样鼓起，胸口尽量保持不动；
3. 吸气后**屏息停留2秒**，不憋气、不用力；
4. 用嘴巴**缓慢呼气6秒**，感受腹部完全收缩，把气息彻底吐出；
5. 重复循环5-10次，直至情绪平稳、躯体放松。
## 三、技术目的与价值（为什么用）
腹式呼吸直接激活**副交感神经**，快速降低心率、缓解躯体紧张，是最便捷的焦虑“紧急刹车”技术，能快速平复情绪波动。
## 四、标准话术示例
“来，把一只手放在肚子上，我们用鼻子慢慢吸气，感受肚子鼓起来，再慢慢吐气，把所有紧张都呼出去，跟着我的节奏就好。”
