# 反刍思维阻断技术
## 一、适用时机（什么时候用）
用户**反复回想负面事、思维循环、停不下来**时使用。
## 二、核心操作步骤（怎么用）
1. 默念“停止”；
2. 物理刺激打断（捏手腕）；
3. 立刻做现实活动。
## 三、技术目的与价值（为什么用）
**快速切断反刍**，停止情绪内耗。
## 四、标准话术示例
“停！不想了，我们现在做一件眼前的小事，把思绪拉回来。”
