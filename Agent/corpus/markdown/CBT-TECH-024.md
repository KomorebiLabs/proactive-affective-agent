# 强迫反应预防技术
## 一、适用时机（什么时候用）
用户出现**强迫思维、想要执行强迫仪式**时使用。
## 二、核心操作步骤（怎么用）
1. 面对触发情境；
2. **禁止执行强迫仪式**；
3. 忍受焦虑上升，等待自然消退；
4. 逐步延长时间。
## 三、技术目的与价值（为什么用）
破除**强迫循环**，消除仪式行为依赖。
## 四、标准话术示例
“现在不用去检查/清洗，忍一会儿，焦虑会自己下去，不用怕。”
