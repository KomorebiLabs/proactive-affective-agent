# 情绪危机应对预案技术
## 一、适用时机（什么时候用）
用户**情绪重度发作、预警危机、即将崩溃**时使用。
## 二、核心操作步骤（怎么用）
1. 识别预警信号；
2. 按预案步骤：放松→联系支持→安全场所；
3. 随身携带预案卡片。
## 三、技术目的与价值（为什么用）
**标准化危机自救**，防止情绪失控升级。
## 四、标准话术示例
“按照我们准备好的预案做，先深呼吸，再联系支持你的人，你会安全的。”
