# 呼吸再训练技术
## 一、适用时机（什么时候用）
用户因焦虑出现**呼吸过快、胸闷、头晕、手脚发麻、过度换气**，即将进入惊恐发作时使用。
## 二、核心操作步骤（怎么用）
1. 引导用户闭嘴，用鼻腔平稳吸气，默数**4拍**；
2. 短暂屏息**2拍**，保持身体放松；
3. 用嘴巴缩唇缓慢呼气，默数**6拍**，延长呼气时间；
4. 保持节奏稳定，拒绝浅快呼吸，持续3-5分钟；
5. 告知用户：呼气长于吸气是平复关键。
## 三、技术目的与价值（为什么用）
快速纠正焦虑导致的**病理性呼吸模式**，恢复正常血氧平衡，消除胸闷、头晕等躯体症状，阻止惊恐发作升级。
## 四、标准话术示例
“不要快喘，我们慢慢吸，慢慢呼，呼气比吸气再慢一点，你会感觉胸口越来越轻松，头晕也会慢慢消失。”
