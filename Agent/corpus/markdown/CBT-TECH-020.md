# 成本效益分析技术
## 一、适用时机（什么时候用）
用户**无法放弃有害行为、强迫行为、成瘾冲动**时使用。
## 二、核心操作步骤（怎么用）
1. 列出行为的短期好处；
2. 列出长期危害；
3. 对比权重，看清代价；
4. 建立替代行为。
## 三、技术目的与价值（为什么用）
让用户**清晰看到行为代价**，增强改变动力。
## 四、标准话术示例
“我们把这么做的好处和坏处都写下来，你就会发现，它其实伤害你更多。”
