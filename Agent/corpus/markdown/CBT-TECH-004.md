# 渐进式肌肉放松技术
## 一、适用时机（什么时候用）
用户存在**慢性躯体紧张、肩颈僵硬、长期焦虑、失眠、睡前胡思乱想、肌肉紧绷酸痛**时使用，适合安静环境下练习。
## 二、核心操作步骤（怎么用）
1. 采取舒适坐姿或躺姿，全身放松，闭眼；
2. 从**脚部**开始，逐组肌肉先**紧绷5秒**，感受极致紧张感；
3. 紧绷后**突然完全放松10秒**，专注感受放松与酸胀感；
4. 按顺序向上练习：腿部→腹部→手臂→肩膀→颈部→面部；
5. 全程配合缓慢呼吸，循环1-2轮即可。
## 三、技术目的与价值（为什么用）
通过“先紧张后放松”的对比，让用户清晰感知**紧张与放松的差异**，系统性释放躯体积压的压力，深度缓解慢性焦虑与失眠。
## 四、标准话术示例
“现在把你的脚用力绷紧，感受肌肉紧紧缩在一起，坚持住，然后……彻底放松，让所有力气都散掉，感受这种软软的放松感。”
