# 愉悦活动清单构建技术
## 一、适用时机（什么时候用）
用户处于**抑郁快感缺失、觉得一切都没意思、找不到开心的事**，需要唤醒积极情绪时使用。
## 二、核心操作步骤（怎么用）
1. 引导用户回忆**过往所有微小愉悦事件**，全部写进清单；
2. 按** effort（ effort=费力程度）** 分三级：低、中、高；
3. 抑郁急性期**只选低费力活动**（听音乐、晒太阳、喝热饮）；
4. 每日强制完成1-2项，记录情绪变化；
5. 持续更新清单，保留有效愉悦活动。
## 三、技术目的与价值（为什么用）
抑郁会剥夺快乐感知，清单能**降低愉悦行为的启动难度**，用低成本小事唤醒积极情绪体验。
## 四、标准话术示例
“我们不用找大事开心，就找最小的、不用费力的小事，比如晒五分钟太阳，喝一口喜欢的水，一点点把快乐找回来。”
