# 压力接种训练技术
## 一、适用时机（什么时候用）
用户面临**长期压力、反复压力事件**，需要提前提升抗压能力时使用。
## 二、核心操作步骤（怎么用）
1. 认知准备：了解压力反应，识别压力思维；
2. 技能学习：掌握放松、认知重构、问题解决；
3. 实战练习：在模拟压力场景中反复使用技能。
## 三、技术目的与价值（为什么用）
如同“心理疫苗”，**提前储备抗压技能**，增强压力抵抗力。
## 四、标准话术示例
“我们现在提前练好应对压力的本领，以后压力来的时候，你就不会那么慌了。”
