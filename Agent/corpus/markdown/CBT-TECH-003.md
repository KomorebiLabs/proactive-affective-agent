# 行为激活小任务技术
## 一、适用时机（什么时候用）
用户陷入**抑郁情绪、行动力完全低下、不想起床、回避所有活动、对任何事没兴趣、自我否定**，需要恢复基本生活能力时使用。
## 二、核心操作步骤（怎么用）
1. 摒弃“大目标”，设定**极低难度、5分钟内能完成**的微小任务（如：起床、叠被子、倒一杯水、开窗通风）；
2. 明确任务完成时间，不拖延、不追求完美，允许“粗糙完成”；
3. 任务完成后，引导用户记录感受，给予**自我肯定与认可**；
4. 情绪逐步回升后，缓慢升级任务难度（散步10分钟、简单洗漱、回复一条消息）。
## 三、技术目的与价值（为什么用）
打破抑郁核心恶性循环：**情绪低落→拒绝行动→情绪更低落**，用极小行为启动行动力，通过行为改变反向带动情绪回升。
## 四、标准话术示例
“我们现在不要求做大事，就做一件最小的事，比如站起来倒一杯水，做完之后，你就已经很棒了，我们一步一步来。”
