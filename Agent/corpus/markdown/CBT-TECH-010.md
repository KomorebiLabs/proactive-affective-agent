# 拖延问题解决技术
## 一、适用时机（什么时候用）
用户面对任务**迟迟不开始、恐惧启动、完美主义拖延、越拖越焦虑**时使用。
## 二、核心操作步骤（怎么用）
1. 把大任务**拆解为5分钟能完成的极小步骤**；
2. 放弃完美要求，允许**先完成、再优化**；
3. 设定明确起止时间，屏蔽手机等干扰；
4. 完成第一步后，奖励自己，继续推进。
## 三、技术目的与价值（为什么用）
拖延的核心是**启动困难**，极小步骤降低阻力，打破“拖延→自责→更拖延”循环。
## 四、标准话术示例
“我们不要求做完整个任务，就做最开始的一小步，5分钟就够，先动起来，你就不会那么怕了。”
