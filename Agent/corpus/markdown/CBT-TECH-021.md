# 双重标准矫正技术
## 一、适用时机（什么时候用）
用户**自我攻击、自我苛责、用最高标准要求自己**时使用。
## 二、核心操作步骤（怎么用）
1. 发现：对人宽容、对己残忍；
2. 写下对朋友的安慰话；
3. 用同样的话对待自己；
4. 建立统一评价标准。
## 三、技术目的与价值（为什么用）
消除**自我苛责**，学会自我友善。
## 四、标准话术示例
“如果你的朋友这样，你会骂他吗？不会，那你也不要这样骂自己。”
