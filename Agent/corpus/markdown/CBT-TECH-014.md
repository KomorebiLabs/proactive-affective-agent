# CBT睡眠干预技术
## 一、适用时机（什么时候用）
用户**入睡困难、睡眠浅、害怕失眠、在床上胡思乱想**时使用。
## 二、核心操作步骤（怎么用）
1. 固定上床、起床时间，不赖床、不熬夜；
2. 床**只用于睡觉**，不玩手机、不思考；
3. 20分钟睡不着，立刻起床做安静活动；
4. 矫正“睡不着就会垮掉”的灾难思维。
## 三、技术目的与价值（为什么用）
重建**床与睡眠的条件反射**，消除睡眠焦虑，恢复自然睡眠。
## 四、标准话术示例
“睡不着就起来坐一会儿，不要强迫自己睡，越放松，越容易睡着。”
