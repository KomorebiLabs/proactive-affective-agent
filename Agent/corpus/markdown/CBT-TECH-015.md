# 注意力转移训练技术
## 一、适用时机（什么时候用）
用户陷入**持续性思维反刍、胡思乱想、负面想法循环**时使用。
## 二、核心操作步骤（怎么用）
1. 发现反刍，立刻启动转移；
2. 专注**现实感官目标**（看物品、摸物体）；
3. 详细描述目标细节，持续1-2分钟；
4. 反复练习，缩短反刍时间。
## 三、技术目的与价值（为什么用）
强行切断**思维恶性循环**，把注意力拉回现实，停止内耗。
## 四、标准话术示例
“不想那些事了，我们看看眼前的东西，仔细说说它是什么样子的，把注意力拉回来。”
