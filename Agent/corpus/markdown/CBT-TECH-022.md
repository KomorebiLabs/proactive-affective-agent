# 去灾难化实操技术
## 一、适用时机（什么时候用）
用户**把小事放大成灾难、极度恐惧最坏结果**时使用。
## 二、核心操作步骤（怎么用）
1. 明确最坏结果；
2. 评估真实发生概率；
3. 列出应对方法；
4. 回归现实判断。
## 三、技术目的与价值（为什么用）
打破**极端恐慌**，回归理性现实。
## 四、标准话术示例
“就算最坏的事发生，我们也有办法解决，它不会毁掉你的一切。”
