# 想象暴露疗法技术
## 一、适用时机（什么时候用）
用户对**特定场景、事物、画面存在强烈恐惧**，无法直接现实接触时使用。
## 二、核心操作步骤（怎么用）
1. 引导用户进入深度放松状态；
2. 由**低强度恐惧画面**开始，逐步描述想象场景；
3. 让用户停留在想象中，直至焦虑下降50%以上；
4. 逐级升级恐惧强度，反复练习。
## 三、技术目的与价值（为什么用）
通过想象实现**恐惧习惯化**，降低恐惧敏感度，消除内心恐惧反应。
## 四、标准话术示例
“现在你慢慢放松，我们轻轻想象那个画面，不用害怕，焦虑会慢慢降下来，我陪着你。”
