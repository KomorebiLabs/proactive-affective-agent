# 完美主义认知矫正技术
## 一、适用时机（什么时候用）
用户因**必须完美、不完美就是失败**导致焦虑、拖延、自我否定时使用。
## 二、核心操作步骤（怎么用）
1. 识别核心执念：“必须100分，否则彻底失败”；
2. 用**“足够好”替代“绝对完美”**；
3. 接受失误是正常现象，不定义自我价值；
4. 允许自己粗糙完成任务。
## 三、技术目的与价值（为什么用）
完美主义是焦虑与拖延的核心源头，矫正后能**降低心理压力**，提升行动力与自我接纳。
## 四、标准话术示例
“这件事不用做到最好，做到够用、能完成就很好了，不完美一点都不可怕。”
