# 苏格拉底式提问技术
## 一、适用时机（什么时候用）
用户**陷入极端思维、固执负面想法、无法理性思考**时使用。
## 二、核心操作步骤（怎么用）
1. 提问：支持想法的证据是什么？
2. 提问：有没有其他可能性？
3. 提问：朋友遇到这事，你会怎么劝？
4. 引导用户自己得出理性结论。
## 三、技术目的与价值（为什么用）
不强行说服，**引导用户自我觉醒**，修正不合理思维。
## 四、标准话术示例
“你觉得这件事一定是坏事，有什么证据能证明呢？有没有别的可能？”
