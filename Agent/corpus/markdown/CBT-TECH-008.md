# 社交焦虑角色扮演技术
## 一、适用时机（什么时候用）
用户即将面对**社交场景、公开表达、人际对话**，提前预演降低焦虑；或社交后复盘优化行为时使用。
## 二、核心操作步骤（怎么用）
1. 设定具体社交场景（打招呼、表达意见、课堂发言）；
2. 咨询师/同伴扮演互动对象，用户模拟真实应对；
3. 演练结束后，**具体反馈行为问题**（语速、眼神、姿态）；
4. 修正后反复练习，直至焦虑明显下降；
5. 逐步过渡到真实社交场景。
## 三、技术目的与价值（为什么用）
通过**模拟预演消除未知恐惧**，建立适应性社交行为，降低社交焦虑，提升自信。
## 四、标准话术示例
“现在我就是你要沟通的人，你试着把想说的话慢慢说出来，不用怕说错，我们练熟了，真实场景就不会慌了。”
