# 5-4-3-2-1着陆技术

## 一、适用时机（什么时候用）

当用户出现**急性焦虑爆发、惊恐发作、大脑空白、情绪极度上头、解离感强烈**，无法专注当下、陷入极端恐慌或胡思乱想时，立即使用。

## 二、核心操作步骤（怎么用）

1. 引导用户平稳呼吸，保持睁眼状态，将注意力拉回现实环境；
2. 依次完成五感着陆：说出**5个**眼前能看到的具体物品（描述细节）；
3. 用手触摸并说出**4样**身边真实存在的物体（感受材质、温度）；
4. 仔细聆听并说出**3种**周围环境里的声音；
5. 感知并说出**2种**能闻到的气味（清淡气味即可）；
6. 感受**1种**口腔内的味道或身体与衣物/座椅的触感；
7. 全程保持缓慢语速，一步一步引导，不催促、不加速。

## 三、技术目的与价值（为什么用）

通过强制调动**五感感官**，快速切断负面思维反刍与焦虑循环，把意识从未来恐惧/过去痛苦中拉回**当下现实**，快速降低生理唤醒水平，终止急性情绪崩溃。

## 四、标准话术示例

"我知道你现在特别慌、特别难受，没关系，我们一起做一个最简单的小练习，马上就能缓过来。你先看着周围，告诉我，你能看到5样什么东西？慢慢说就好。"
