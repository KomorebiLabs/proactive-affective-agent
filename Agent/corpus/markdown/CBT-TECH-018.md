# 社交技能基础训练技术
## 一、适用时机（什么时候用）
用户**社交能力不足、不敢表达、不会倾听**时使用。
## 二、核心操作步骤（怎么用）
1. 练习适度眼神接触；
2. 平稳语速、适中音量；
3. 认真倾听，不打断；
4. 清晰表达自身需求。
## 三、技术目的与价值（为什么用）
提升**社交实操能力**，减少焦虑，建立自信。
## 四、标准话术示例
“慢慢说，看着对方的眼睛，把你想说的话讲清楚就可以了。”
