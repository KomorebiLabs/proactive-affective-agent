# 每日活动计划表技术
## 一、适用时机（什么时候用）
用户**生活失去秩序、全天躺卧、无任何计划、抑郁性停滞**，需要重建日常行为节奏时使用。
## 二、核心操作步骤（怎么用）
1. 按**小时为单位**划分全天24小时，填充具体、简单的活动；
2. 活动分为两类：**愉悦活动**（带来快乐）、**成就活动**（带来掌控感）；
3. 任务难度由极低开始，拒绝过高目标，避免挫败感；
4. 每完成一项，标注愉悦度与掌控感（0-10分）；
5. 每日固定执行，逐步形成规律。
## 三、技术目的与价值（为什么用）
用结构化安排填补抑郁带来的**空虚与停滞**，重建生活掌控感，通过稳定行为持续改善抑郁情绪。
## 四、标准话术示例
“我们把今天的时间分成一小块一小块的，每块只做一件小事，完成一个就打一个勾，你会慢慢找回对生活的掌控感。”
