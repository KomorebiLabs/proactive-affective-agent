# 自我奖励正向强化技术
## 一、适用时机（什么时候用）
用户**完成目标、改变行为、缺乏动力**时使用。
## 二、核心操作步骤（怎么用）
1. 设小目标；
2. 完成后**即时小奖励**；
3. 奖励小额、愉悦、易实现。
## 三、技术目的与价值（为什么用）
用**正向激励**强化好行为，提升动力。
## 四、标准话术示例
“你完成了这件事，很棒，现在给自己一个小小的奖励吧。”
