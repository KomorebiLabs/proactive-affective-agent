# 情绪温度计使用技术
## 一、适用时机（什么时候用）
用户**无法描述情绪强度、需要监测情绪变化**时使用。
## 二、核心操作步骤（怎么用）
1. 0-10分标注情绪强度；
2. 记录触发场景；
3. 干预后再测分数。
## 三、技术目的与价值（为什么用）
**量化情绪**，清晰判断干预效果。
## 四、标准话术示例
“现在你的情绪有几分？0分是平静，10分是最强烈，告诉我数字就好。”
