# 现实分级暴露技术
## 一、适用时机（什么时候用）
用户**长期回避恐惧场景、社交回避、特定恐惧**时使用。
## 二、核心操作步骤（怎么用）
1. 建恐惧阶梯（0-100分）；
2. 从最低级开始暴露；
3. 停留至焦虑下降50%；
4. 逐级进阶，不逃避。
## 三、技术目的与价值（为什么用）
通过**习惯化消除恐惧**，彻底打破回避。
## 四、标准话术示例
“我们从最简单的开始，不用怕，待一会儿，焦虑就会降下来。”
