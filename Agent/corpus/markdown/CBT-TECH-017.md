# 正念CBT基础觉察技术
## 一、适用时机（什么时候用）
用户**想法杂乱、情绪内耗、无法平静**时使用。
## 二、核心操作步骤（怎么用）
1. 静坐，专注呼吸；
2. 想法飘走，不评判，轻轻拉回；
3. 把情绪当过客，不对抗、不沉浸。
## 三、技术目的与价值（为什么用）
实现**思维解离**，减少内耗，获得内心平静。
## 四、标准话术示例
“跟着呼吸，想法来了就让它过，我们不跟着它走，安安静静待一会儿。”
