# AI agent核心功能模块之四：利用知识库中的相关心理学领域知识对用户进行（三个状态）的有效心理情感干预（主要就涉及知识库）---涉及很多方面问题和技术，知识库之类的，比较难说！需要细致的处理了（RAG相关！）

早期/前期阶段我们已经探讨并且分发心理学知识库的任务了，如何利用我们准备好的知识库心理学领域知识/知识卡片呢？Ai agent如何利用这里面的知识呢？如何进行具体的设计？

## RAG知识库搭建框架与逻辑过程概括

### 一、知识库构建

- **数据源**：心理学专家整理的Markdown知识卡片，每张卡片包含YAML元数据（如情绪标签、认知扭曲类型、适用场景等）和正文内容（操作步骤、话术示例等）。
- **预处理**：
  - 解析YAML头，提取元数据，作为文档的metadata字段。
  - 可选择按标题切分卡片（如保持完整卡片或拆分为更细的语义块），便于检索粒度控制。
- **向量化存储**：
  - 使用Embedding模型（如text-embedding-3-small或all-MiniLM-L6-v2）将文档内容转化为向量。
  - 将向量及对应的元数据存入向量数据库（如Chroma、Milvus），形成可检索的知识库。

### 二、知识检索触发时机

- **核心触发点**：在Agent决策流程中，当需要生成具体干预回复时（即generate_reply节点），且前序decide_intervention已决定执行干预（suggested_action为intervene）。
- 也可在轻度干预时选择性触发，但通常只在需要显式对话时检索。

### 三、检索查询构建

- **查询输入**：结合用户当前情绪状态（emotion_vector.primary_emotion）、认知扭曲列表（cognitive_distortions）、用户最新消息（可选）等，构造自然语言查询。
- **示例查询形式**：“用户感到焦虑，伴有灾难化认知扭曲，说：‘我不行了’”，便于语义匹配。

### 四、检索方法

- **混合检索**：
  - 元数据过滤：根据当前情绪和认知扭曲，从知识库中筛选出相关类型的卡片，缩小检索范围。
  - 向量相似度检索：在过滤后的结果中，计算查询向量与文档向量的余弦相似度，返回最相似的K条。
- 或直接向量检索：将查询文本直接向量化，在全局知识库中检索最相似的K条，利用元数据作为后过滤或排序依据。
- **重排序（可选）**：对初步检索结果，可调用轻量级重排序模型（reranker）进一步优化顺序，确保最相关内容排在前面。

### 五、结果处理与生成回复

- 将检索到的K个文档内容拼接成上下文，与用户状态、任务指令一起填入Prompt模板。
- **Prompt设计要点**：
  - 明确角色（CBT心理支持助手）。
  - 提供用户当前状态（情绪、认知扭曲、消息）。
  - 插入检索到的知识卡片内容。
  - 指定生成要求（共情、选择合适方法、自然语言）。
- 调用大语言模型（如DeepSeek）生成最终回复。
- 回复可能包含干预话术、引导问题等，直接用于与用户交互。

### 六、知识库的维护与扩展

- **增量更新**：新增或修改卡片时，重新向量化并插入向量数据库，支持动态扩充。
- **版本管理**：卡片ID可带版本，旧版本可标记废弃或保留供分析。
- **定期评估**：通过用户反馈或专家审核，优化卡片内容和检索效果。

### 七、整体流程示意图

```text
知识卡片 (Markdown) → 加载与元数据提取 → 向量化 → 存入向量数据库      ↑
用户当前状态 → 构造查询 → 检索相似卡片 → 注入Prompt → LLM生成回复 → 输出给用户
```

此框架确保了Agent能根据用户实时情绪和认知问题，动态调用最相关的心理学知识，实现专业、个性化的情感干预。

# 5-4-3-2-1着陆技术

## 什么是着陆技术
当人处于高度焦虑、恐慌状态时，大脑会被灾难性的想法占据。着陆技术通过调动五种感官，将注意力从内心的恐慌转移到外部现实，从而快速降低焦虑水平。

## 操作步骤
按顺序引导用户完成以下动作：

1. **看（5）**：说出你看到的 **5** 样东西  
   *例：“告诉我你周围能看到哪5样东西？——比如：电脑屏幕、水杯、窗户、桌上的笔、你的手。”*

2. **触（4）**：感受你能触摸到的 **4** 样东西  
   *例：“现在，试着去触摸你身边的4样物品，感受它们的质感——比如：桌面的冰凉、衣服的柔软、椅子的硬实、手机的棱角。”*

3. **听（3）**：仔细听你能听到的 **3** 种声音  
   *例：“闭上眼（可选），仔细听听周围，告诉我你听到了哪3种声音？——空调声、键盘敲击声、远处的汽车声。”*

4. **闻（2）**：闻一闻你能闻到的 **2** 种气味  
   *例：“试着深吸一口气，有没有闻到什么味道？——咖啡香、空气清新剂、或者只是普通的气味。”*

5. **感受（1）**：觉察身体的一个部位或感受  
   *例：“最后，感受一下你的身体，比如双脚踩在地上的感觉，或者手心触摸桌面的温度。”*

## 话术示例
“我们现在一起做个练习，帮你放松下来。先看看周围，告诉我你看到了哪5样东西？……好的，接下来，摸摸身边，告诉我你摸到了哪4样？……仔细听，能听到哪3种声音？……有没有闻到什么味道？哪怕很淡也行……最后，感受一下你的身体，脚踩在地上的感觉，或者手放在桌上的触感。”

## 为什么有效
- 强制大脑从内部恐慌转向外部感官输入
- 激活副交感神经系统，降低生理唤醒
- 通过具体、可操作的任务，打破灾难性思维的循环

## 注意事项
- 如果用户说“我什么都闻不到”，可以回应：“没关系，那我们就试试其他几种。”
- 保持语气温和、缓慢，给用户足够时间完成每个步骤。
- 如果用户处于极度恐慌，可以先引导深呼吸一次再开始。
