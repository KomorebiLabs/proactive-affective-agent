@workspace 我们现在要为 Agent 增加 "Function Calling / Tool Calling" 的能力，并直接集成真实的 Notion API，作为项目最大的亮点之一。

【任务目标】
实现一个“帮用户在 Notion 中记录情绪日记”的工具，使用 Python + LangChain 的 `@tool` 装饰器，并调用真实的 Notion API（通过 `notion-client` 库）。要求从环境变量读取 API 密钥和数据库 ID。

【具体步骤】

1. **安装依赖**  
   在 `requirements.txt` 中确保包含 `notion-client`，并在代码中导入。

2. **创建工具函数**  
   在 `src/agent/tools/notion_tool.py` 中编写：
   - 使用 `@tool` 装饰器。
   - 定义参数（event_description, emotion_type, intensity, ai_advice），参数 Schema 通过详细的 Docstring 描述。
   - 在函数内部：
     - 从环境变量 `os.getenv("NOTION_API_KEY")` 和 `os.getenv("NOTION_DATABASE_ID")` 获取配置。
     - 使用 `notion_client.Client(auth=api_key)` 初始化客户端。
     - 构造新页面（page）数据，根据数据库列名映射属性（例如 “情绪” 对应 select 选项，“强度” 对应 number，“触发事件” 对应 rich_text 等）。
     - 调用 `client.pages.create(parent={"database_id": database_id}, properties=properties)`。
     - 成功后返回 JSON 字符串，包含 `success: true` 和创建的页面 URL（可从返回的页面对象中拼接：`https://www.notion.so/{page_id}`）。
     - 捕获异常，返回 `success: false` 和错误信息。

3. **在 Agent 中绑定工具**  
   - 在 `src/agent/nodes/generate_reply.py` 中导入 `record_mood_diary`。
   - 在调用 LLM 前，用 `llm.bind_tools([record_mood_diary])` 将工具绑定。
   - 处理 LLM 返回的 `tool_calls`，执行工具并将结果（可选）反馈给用户或记录日志。

【输出要求】
- 直接输出 `src/agent/tools/notion_tool.py` 的完整代码。
- 输出对 `generate_reply.py` 的修改部分（如果已有，则给出增量代码片段）。
- 代码中包含必要的导入、类型注解、错误处理和日志。
- 说明如何在 `.env` 中配置环境变量（在代码注释中提及即可）。

【注意事项】
- 不要使用 Mock，必须调用真实 Notion API。
- 数据库列名需与用户实际创建的列一致（示例：日期、情绪、强度、触发事件、AI 建议）。如果列名不同，请在代码中预留适配注释。
- 确保返回的 URL 是用户可点击访问的 Notion 页面链接。
